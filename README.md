# Punto Brasil · Precios y stock

App web (instalable en celular y tablet) para calcular precios de venta, asignar códigos y llevar el stock y las ventas de Punto Brasil.

- Página estática publicada con GitHub Pages.
- Datos y usuarios en Supabase (solo los correos autorizados ven los datos).
- Este repositorio solo tiene código: no contiene datos de productos ni claves privadas.
